# LUDORA

A responsive application catalog for browsing, discovering, and downloading software packages, tools, and digital media. Designed with a cross-platform architecture and an adaptive interface.

---

## Features

- **Application Catalog:** Filter applications across multiple categories including Games, Tools, Productivity, Showcase, and Audio & Music.
- **Featured Hero Showcase:** Automated cross-fade carousel highlighting featured releases.
- **Update Management:** Integrated update notifications and detailed patch notes.
- **Offline Diagnostics:** Real-time network detection with automated connection failure overlays.
- **Adaptive Interface:** Dynamic dark and light theme switching with vector-based SVG icons.
